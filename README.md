## Como experimentar

Abra uma aplicação, combine filtros e explore os detalhes. Nas simulações de processamento, avance pelas etapas e experimente pausa, falha recuperável e nova tentativa. Restaure a demonstração para começar novamente.

## Sobre este material

**Demonstração — dados fictícios.** As aplicações usam dados determinísticos e simulações no navegador. Não consultam sistemas fiscais reais, não emitem guias válidas e não enviam comunicações operacionais. Valores, empresas, prazos e indicadores são ilustrativos.

O hub foi desenvolvido em React, TypeScript e Vite, com páginas carregadas por rota. Este repositório documental contém somente a apresentação dos casos e links públicos. O código das demonstrações e das automações operacionais não integra este material.

Os casos descrevem comportamentos demonstrados, sem atribuir resultados comerciais medidos, clientes ou economias aos cenários fictícios.
